# P4 教师匹配与批量导出验证

日期：2026-11-14。

## 已交付行为

教师在岗位详情进入学生排名，查看姓名、专业、年级、规则分、技能差距及到岗日期。只有学生参与，同分按ID排序；日期为有效YYYY-MM-DD且包含截止当天，历史坏日期显示未知。没有岗位技能时显示未分析，不误报有效零分。匹配原因与三条建议按需调用AI，规则分不受AI影响。

学生资料新增电话、邮箱和默认未勾选的教师导出授权。专用字段有长度与格式检查，校验失败保留输入；联系方式/授权变化使版本递增，其他资料变化不增加该版本。旧页面或缺少版本的联系方式变更被拒绝，避免旧表单重新开启已撤回授权。许可只控制专用字段；自由文本中的个人信息不自动脱敏，页面已说明。

教师勾选1–10人创建独立岗位定制简历任务，快照岗位、资料和当时的授权；不读取、覆盖或修改学生私人简历和面试记录。未授权时电话/邮箱为空。成功项生成DOCX，ZIP含安全姓名/学生ID/岗位文件名和manifest.csv；部分失败可下载成功项并只重试失败项，全失败不提供空ZIP。修改原资料后如需新内容应创建新任务，重试仍使用原快照。

任务仅创建者教师可查看/下载，24小时后过期。生成前后、打包及下载检查联系方式版本；撤回许可或修改联系方式会使旧任务失效，并清理其文件和敏感快照。已经下载的文件无法撤回。下载校验以请求时的许可为准，不能停止已经发送的字节。

## 可靠性和隐私

- 数据库唯一键保证创建幂等，重复提交不新增任务；条件更新保护任务和项目状态，失效终态不会被旧后台结果恢复。
- 生成与文件IO在长事务外执行，消费者一次处理一项；重启恢复pending状态，保留成功文件。崩溃恢复可能再次调用AI，不承诺供应商计费恰好一次。
- 文件位于私有目录，UUID命名，不公开挂载。Windows文件占用时保留失败删除的引用并后台重试；同时在启动及每轮任务间回收无引用的本模块UUID文件，跳过人工文件/目录/符号链接。
- 日志只包含对象编号、数量、状态及许可布尔值，不记录电话、邮箱、简历正文或原始服务错误。
- CSV固定字段为事件ID、用户ID、真实姓名、事件、北京时间（含+08:00）和IP；匿名事件保留空姓名，不把登录输入当真人姓名，不导出payload、UA或联系方式。
- CSV有BOM、标准转义与公式前缀防护；生成器独立管理数据库会话并在结束时关闭，下载响应no-store。日期留空默认最近30天。

## 本地升级及使用

已有数据库须先停止所有服务，再执行：

```powershell
.\.venv\Scripts\python.exe -m scripts.migrate_p4
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

迁移先用SQLite backup备份，再添加缺失联系方式字段；重复运行不改数据。备份为原数据库旁的 `app.db.p4-backup-时间戳`；新任务表由启动create_all创建。本机已完成备份迁移，既有学生默认为未授权。

教师登录后从工作台或岗位详情进入“学生匹配与批量简历”；工作台可找回最近五项任务。教师注册仍需本地 `.env` 配置的 `TEACHER_INVITE_CODE`；无邀请码时教师注册关闭，不自动创建公开密码账号。

填写本地 `.env` 中的 `DEEPSEEK_API_KEY` 后重启，才能真实生成AI解释和岗位定制简历；排名/CSV不需要Key。`RESUME_EXPORT_WORKER_ENABLED`默认true，测试关闭自动消费者。继续保持同数据库单应用实例、单Uvicorn worker；面试和导出各一个消费者，优雅关闭等待当前有界请求结束。
