## 已实现的阶段与验收缺口

| 里程碑 | 源码已实现 | 剩余验收 |
| --- | --- | --- |
| P1 基础业务 | 三角色认证和工作台、岗位发布编辑、岗位技能拆解与修订、学生资料、规则匹配 | 纳入真实模型与公网环境验证 |
| P2 定制简历 | 来源摘选、版本校验、A4 预览、DOCX 和浏览器打印 PDF | 真实模型摘选质量与目标客户端分页 |
| P3 逐题语音 | 录音与上传、转码、供应商接口、题目与追问、评估报告、失败重试和恢复 | 真实 ASR／TTS 和模型闭环，移动端实机，课程语音替代视频口径待确认 |
| P4 教师工具 | 排名与到岗筛选、AI 解释、联系方式授权、批量 DOCX ZIP、使用记录 CSV | 真实解释与导出质量，公网并发场景 |
| P5 公网与课程交付 | 具备本地启动、健康检查、迁移和交接文档 | 公网部署、真人试用及课程材料待完成 |

## 后续优先级与里程碑

| 优先级 | 待开展工作 | 验收条件 |
| --- | --- | --- |
| 最高 | 确认课程口径，并在隔离环境完成真实供应商联调 | 确认语音能否替代视频。岗位拆解、简历、默认五题面试、教师解释和 ZIP 均有真实调用记录，记录延迟、费用、失败和恢复结果 |
| 高 | 补齐公网安全和运维能力 | 会话强密钥和 HTTPS Cookie 生效，验证 CSRF 防护与限流。确认私有音频和审计数据留存规则，完成 SQLite 与私有文件的备份恢复演练 |
| 高 | P5 单实例部署和试用 | 公网 HTTPS、`/healthz`、进程托管与任务恢复可用。用移动端实机验证录音和上传。在课程口径确认后招募至少 10 位真人并收集经同意的证据 |
| 中 | 课程材料和演示 | 按确认要求准备技术总结、测试报告、精益画布、宣传视频、答辩材料与演示方案。提交格式与证据标准待确认 |
| 后续评估 | 扩容和长期工程维护 | 依据验证数据评估任务扫描、排名查询、迁移工具及任务队列升级。是否引入新组件、容量目标和排期均待确认 |

各阶段按 [仓库开发指南](../AGENTS.md) 先确认范围，再实施并验收。
