# P4 教师匹配与批量导出实施记录

用户于2026-11-14确认本计划，并决定在学生资料中增加可选联系方式，由学生主动授权教师导出专用电话和邮箱字段。

## 功能与验收

1. 教师岗位排名：复用既有技能规则，仅学生参与，分数降序/ID升序；真实日期筛选包含当天，历史坏日期显示未知；无岗位技能显示未分析。AI仅按需解释，不能更改规则分。
2. 联系方式：默认不共享；电话40字、邮箱120字，保存校验及epoch条件更新，过期表单不能重新授权或覆盖撤回。其他资料变化不增加联系方式版本。
3. 独立导出：每批1–10位学生，岗位/资料/许可快照，数据库持久任务，复用P2事实摘选及DOCX模板；不读写私人Resume或面试记录。
4. 任务可靠性：唯一请求标识防重复创建，条件更新防重和终态复活；部分成功打包并附清单，仅重试失败项；重启复用成功项。24小时过期，联系方式撤回或变化使旧任务失效。
5. 私有文件：创建者教师才能下载；安全文件名与UUID存储，删除占用失败保留引用重试，恢复及运行期间回收未引用的本模块UUID文件，保留人工文件和引用文件。
6. 使用记录：北京时间日期过滤、50条列表分页、完整结果流式CSV；UTF-8 BOM、公式防护、匿名不冒名、独立流式Session，导出前固定最大事件ID。

## 数据及接口

- StudentProfile新增phone、email、share_contacts、contact_revision，默认空/未授权/0；离线备份幂等迁移脚本为 `python -m scripts.migrate_p4`。
- 新增ResumeExportTask和ResumeExportItem保存创建者、幂等键、快照、24小时期限、状态和私有文件引用；新表随启动创建。
- `/teacher/jobs/{id}/matches`与学生解释接口、岗位下批量任务创建接口、任务页面/status/retry/download、`/teacher/usage`及`/teacher/usage/export.csv`。
- 在教师工作台展示最近五项本人任务，岗位详情可进入排名；原始学生资料联系方式只在本人资料页编辑。
