## 交付行为

学生从工作台、导航或岗位详情进入简历列表，选择开放岗位生成独立简历。AI 仅返回教育、技能、经历描述和奖项的来源编号；服务器验证编号、重复条目与字段长度，再回填学生原文。岗位信息用于相关性选择，不成为学生经历。

分组表单可编辑姓名、电话、邮箱、求职意向、简介及各类经历；修改只保存在简历中。保存采用版本条件 UPDATE；过期提交返回409，校验错误返回422并保留输入及原提交版本。生成失败不保存半成品；导出失败不修改内容。HTML显示、保存、打印、导出均要求学生身份与记录归属。

生成、保存、DOCX导出写入使用事件，payload只包含简历/岗位编号及版本；不记录正文或联系方式。DOCX在内存生成，不持久化个人文件。

## 浏览器与排版检查

使用本机 Edge 的自动化浏览器验证桌面与390px移动视口：表单正确加载、修改保存后刷新保留、未保存修改时阻止打印入口、移动页面不横向溢出。A4预览按容器宽度缩放；独立打印页仍用原始尺寸。

短资料、典型资料、1200字上限资料均用浏览器生成PDF；同时将相同DOCX用本机Microsoft Word实际打开并导出PDF，以Poppler渲染图片检查：

## 使用与限制

- 打印设置：A4、100%缩放、关闭浏览器页眉页脚；采用模板默认15mm页边距。
- 1200字约束及高度预警不等于所有输入均能保证精确分页；长英文、手工换行和不同字体均可能改变页数。导出后以目标客户端预览为准，超限返回编辑页精简，不裁切正文。
- 本轮没有调用真实DeepSeek接口，测试使用FakeLLM；真实模型的摘选质量、响应时间及费用需在配置Key后联调。
- 已实际验证Edge和Word，未实际验证Chrome、WPS、iOS Safari、Android Chrome。
- Python 3.13下有现有Starlette及SQLAlchemy `datetime.utcnow()` 弃用警告；未在本轮修改P1时间存储规则。
- P2实施时目录缺少`.git`，当时未执行Git操作；后续交接已从远端恢复`p1-foundation`历史，最新状态以HANDOVER和git log为准。
