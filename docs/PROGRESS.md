### 本机免费模型联调

- 本机使用 Ollama 的 `qwen2.5:3b` 处理文本，faster-whisper `small` 转写中文录音，Windows 中文音色合成题目。模型服务仅监听回环地址，配置记录在本机 `.env`。
- 用虚构测试账号完成岗位技能提取、学生简历生成与 DOCX 下载、教师匹配解释及 ZIP 导出。五题语音面试走通了本机读题、样例 WAV 上传、转写、评分、追问和报告生成。
- 简历提示增加各段可用来源编号。面试追问可补入转写原文，保留引用出处、评分及长度校验。隔离环境全量 pytest 为 226 项通过、735 条警告，耗时 72.41 秒。

- 已为本机 Ollama 启用 `LLM_STRUCTURED_OUTPUT=true`，简历和面试使用对应的 JSON Schema，同时保留来源编号、引用与评分校验。补引用后追问超过 500 字时，使用带原文引用的短追问。
- 通过本机启动入口 `.\.venv\Scripts\python.exe -B -m scripts.start_local_ai` 冷启动 Ollama、语音服务和网页。启动器和语音适配器随仓库提供，模型权重保存在本机。
- Edge 模拟麦克风录音验证了两个学生同时提交首题、各自收到转写与评分、跨账号访问被拒绝。首次失败的回答重试恢复。全量 pytest 235 项通过。

### 本机模型审查修复

- 启动器校验子进程的本机模型配置和复用服务身份，监测依赖状态，最多重启两次自有服务。停机先等待网页进程，再关闭语音与文本模型。
- 未锚定的模型追问改用原文和通用追问。严格模式按对象规范化 Schema。本机语音转写在读取采样前校验 90 秒时长和 WAV 帧数。
- 收尾版本复跑隔离回归 **254 项通过、735 条警告，耗时 70.51 秒**。已验证配置冲突时实际冷启动、空闲状态下有序停机，以及在线语音接口拒绝 91 秒样例。在途停机顺序与依赖故障恢复由自动化场景覆盖。
