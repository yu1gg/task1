# P5 部署与课程交付实施计划

**目标**：在隔离环境建立可复跑的回归基线，验证真实模型与语音流程，完成单实例部署准备，并按确认后的课程口径收集试用和交付证据。

**架构**：继续使用 FastAPI 服务端页面、SQLite 与本地私有文件。每个数据库运行一个应用实例和一个 Uvicorn 工作进程。HTTPS 端接、进程托管和备份落点按获批部署环境落实。

**技术栈**：Python、FastAPI、SQLAlchemy、SQLite、pytest、ffmpeg／ffprobe、DeepSeek 与 SiliconFlow。

阶段结果记入 [开发进度](../../PROGRESS.md)。权限、发布范围或数据处理方式发生变化时先确认，再进入对应阶段。

## 1. 隔离回归基线

涉及 `app/`、`scripts/`、`tests/` 和 `pytest.ini`，在当前提交的独立副本中验证。

- [x] 使用已安装依赖的 Python 环境，给测试进程配置 ffmpeg 和 ffprobe 路径。副本不包含真实 `.env` 与业务数据库。
- [x] 运行 `python -B -m pytest -p no:cacheprovider --disable-warnings`，记录通过、失败、跳过和警告数量。
- [x] 使用独立新 SQLite 文件、启用两个消费者，验证首页和 `/healthz` 返回 200，验证应用生命周期可正常退出。

## 2. 真实服务联调与课程验收口径

涉及 [应用配置](../../../app/config.py)、[模型客户端](../../../app/services/llm.py)、[语音客户端](../../../app/services/speech.py) 和 [交接手册](../../../HANDOVER.md)。

- [ ] 确认课程是否接受逐题语音替代视频，以及真人试用和材料的证据要求。
- [ ] 在获准使用的隔离环境配置供应商密钥和音频工具，用测试岗位与虚构学生资料验证岗位拆解、事实摘选简历、默认五题语音报告、教师解释和 ZIP。
- [ ] 记录成功率、异常反馈、延迟及费用。验证供应商失败后的重试路径和保护措施。留存证据时排除密钥和无关个人信息。

## 3. 公网安全准备与恢复演练

预计影响 `app/config.py`、`app/main.py`、认证及写入路由、表单与浏览器脚本，以及相应测试。具体接口与变更范围在该阶段开始前确认。

- [ ] 先确定公网和本地的配置边界。设计并测试 HTTPS Cookie、会话密钥检查、跨站请求防护和登录限流。验证正常表单、录音上传、导出重试、课程演示登录及反向代理场景。
- [ ] 用合成数据演练 SQLite 与私有文件的配套备份。恢复到独立目录后检查数据库完整性、`/healthz` 和资源可读性。旧库升级按交接手册停机执行 P3、P4，保留备份与恢复步骤。
- [ ] 确认音频、导出及审计记录的留存期限、试用告知与访问权限。记录公网环境的日志、容量和任务恢复检查项。

部署主机、域名、证书、访问范围和课程提交格式待确认。生产配置和公网发布在获得相应授权后执行。
